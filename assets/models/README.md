# 本机模型导入

IPA 不包含模型，也不会在运行时联网下载模型。pubspec.yaml 不再打包 assets/models/，因此即使开发机保留模型文件，也不会把它们加入安装包。

## 在 iPhone 上添加已有模型

1. 安装后先打开 App 一次，创建共享目录。
2. 在「文件」App 中进入「浏览」→「我的 iPhone」→「Marine Voice Translator」→ models。
3. 将手机上已有的两个完整模型拷贝到该目录，文件名应分别为：
   - ggml-large-v3-turbo-q5_0.bin
   - qwen2.5-1.5b-instruct-q4_k_m.gguf
4. 重新打开 App，检查 ASR 和 LLM 状态，再在飞行模式下测试。

模型仅放在下载文件夹或其他 App 的目录中，本应用无法自动读取，需要拷贝进本应用的 models 文件夹。已有文件若已在这个目录中，无需重复添加。请使用对应架构、格式的模型，不要将不兼容模型仅改名冒充。App 会检查文件头和最低大小，此检查不等于完整哈希或模型兼容性验证。

## 开发机上的模型文件

模型仍由 .gitignore 排除。开发机如需复现默认模型，可选择运行 ./tool/download_models.ps1，下载脚本固定版本并校验 SHA-256；dart tool/check_offline_models.dart 只用于检查这些开发机文件，不再是 IPA 打包的前提。

两个默认模型合计约 1.69 GB。手机模型的存储和推理内存需求仍然存在；安装包缩小不会改变推理所需内存。App 退到后台时释放原生模型，回到前台后按需重新加载。
